   # Contributing
   ## Branches
   Never commit directly to main. Use feature/short-name, fix/short-name, docs/short-name.
   ## Commits
   Use prefixes: feat:, fix:, docs:, test:, chore:
   ## Pull requests
   - Link the issue (Closes #12)
   - At least 1 teammate approval before merging
   ## Definition of Done
   - [ ] Code works and is reviewed
   - [ ] Tests pass
   - [ ] Docs updated
